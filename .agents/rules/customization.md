# Customization-First Development

For every new feature, ask the user a lot of specific questions to make it as customizable as possible. Cover:

- **Configuration** — Should it be hardcoded, filtered, or have an options page?
- **Styling** — Colors, layout, spacing, presets?
- **Content** — Can items be added/modified/removed?
- **Extensibility** — Hooks, filters, child theme overrides?
- **Integration** — Which editors/formats should it support?

Default to a layered approach: sensible defaults + filters + options storage + admin UI when appropriate.

Expand your menu capabilities. Bulk select, delete, move, and edit navigation menu items with ease.

== Description ==

NavSweeper gives you powerful bulk operations for WordPress navigation menus. Stop editing menu items one by one — select multiple items and perform actions in one click.

= Features =

* **Bulk Delete** — Select and remove multiple menu items at once.
* **Bulk Move** — Move items between menus or reset their parent/order hierarchy.
* **Bulk Edit** — Update label, URL, CSS classes, link target, and description for many items simultaneously.
* **Add Menu Items** — Insert custom links with full control over positioning (above/below a reference item).
* **Select All** — Toggle selection for all items in a menu with one click.
* **Block Theme Compatible** — Automatically registers a default menu location so the Menus screen appears even under block themes like Twenty Twenty-Five.

== Installation ==

1. Upload the `navsweeper` folder to `/wp-content/plugins/`, or install via **Plugins → Add New** and search for "NavSweeper".
2. Activate the plugin through the **Plugins** screen.
3. Go to **Appearance → NavSweeper** to start managing your menus.

== Frequently Asked Questions ==

= I don't see the NavSweeper menu under Appearance =

Make sure you have at least one menu created. Go to **Appearance → Menus** and create a menu first.

= Can I move items between different menus? =

Yes. Select the items you want to move, pick a destination menu from the dropdown, and click **Move Items**.

= Does this plugin work with block themes? =

Yes. NavSweeper automatically registers a default menu location if your theme doesn't have any, ensuring the full menu management interface is available.
